# Keyboard Shortcuts

## Custom App Shortcuts (<kbd>Cmd</kbd> + <kbd>Control</kbd>)

| Shortcut | Action |
| :--- | :--- |
| <kbd>Cmd</kbd> + <kbd>Control</kbd> + <kbd>.</kbd> | Toggle Safari-style **Show Tab Overview** grid |
| <kbd>Cmd</kbd> + <kbd>Control</kbd> + <kbd>/</kbd> | Toggle **Traffic Light Buttons** (Close, Minimize, Maximize — *hidden by default*) |
| <kbd>Cmd</kbd> + <kbd>Control</kbd> + <kbd>N</kbd> | Open **New Tab with URL** (prompts for website URL) |
| <kbd>Cmd</kbd> + <kbd>Control</kbd> + <kbd>B</kbd> | **Save Bookmark** (saves the current page's title and URL) |
| <kbd>Cmd</kbd> + <kbd>Control</kbd> + <kbd>,</kbd> | Change / Toggle **Theme** (Dark / Light) on the active tab |
| <kbd>Cmd</kbd> + <kbd>Control</kbd> + <kbd>Y</kbd> | **Rename** the active tab (custom title shown in Show Tab Overview) |
| <kbd>Cmd</kbd> + <kbd>Control</kbd> + <kbd>F</kbd> | Toggle Full Screen |

---

## Tab Management

| Shortcut | Action |
| :--- | :--- |
| <kbd>Cmd</kbd> + <kbd>T</kbd> | Open a new tab (loads the app's default URL) |
| <kbd>Cmd</kbd> + <kbd>Control</kbd> + <kbd>N</kbd> | Open a new tab and input a custom URL |
| <kbd>Cmd</kbd> + <kbd>Control</kbd> + <kbd>Y</kbd> | Change the active tab's name in Tab Overview |
| <kbd>Cmd</kbd> + <kbd>W</kbd> | Close current tab (or close window if only 1 tab is open) |
| <kbd>Cmd</kbd> + <kbd>Option</kbd> + <kbd>Tab</kbd> | Switch to next tab |
| <kbd>Cmd</kbd> + <kbd>Option</kbd> + <kbd>Shift</kbd> + <kbd>Tab</kbd> | Switch to previous tab |
| <kbd>Cmd</kbd> + Click on any link | Open link in a new in-app tab |
| <kbd>Esc</kbd> | Exit Show Tab Overview |

---

## Navigation & View

| Shortcut | Action |
| :--- | :--- |
| <kbd>Cmd</kbd> + <kbd>R</kbd> | Reload current tab |
| <kbd>Cmd</kbd> + <kbd>+</kbd> | Zoom In |
| <kbd>Cmd</kbd> + <kbd>-</kbd> | Zoom Out |
| <kbd>Cmd</kbd> + <kbd>0</kbd> | Actual Size (Reset Zoom) |
